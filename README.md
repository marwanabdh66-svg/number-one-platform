# NUMBER ONE 👑

منصة عربية لإعداد أفكار الإعلانات وإدارة طلبات التصميم والاشتراكات.

## التشغيل محليًا

1. ثبّت Python 3.10 أو أحدث.
2. ثبّت المتطلبات:

```bash
pip install -r requirements.txt
```

3. شغّل التطبيق:

```bash
streamlit run app.py
```

## إعداد لوحة الإدارة على Streamlit Cloud

من إعدادات التطبيق افتح قسم **Secrets** وأضف القيم التالية، مع استبدال القيم التجريبية بكلمات سر قوية خاصة بك:

```toml
NUMBER_ONE_OWNER_USERNAME = "اكتب_اسم_المالك"
NUMBER_ONE_OWNER_PASSWORD = "اكتب_كلمة_مرور_قوية"
NUMBER_ONE_PASSWORD_SALT = "اكتب_قيمة_عشوائية_طويلة_وثابتة"
```

التطبيق يدعم أيضًا الاسمين القديمين `ADMIN_USERNAME` و`ADMIN_PASSWORD`، لكن يفضّل استخدام اسمي المالك أعلاه.

**لا تضع كلمات المرور أو مفاتيح الخدمات داخل ملفات GitHub.** أضفها في أسرار الاستضافة فقط، ولا تشاركها في المحادثات.

## الوظائف الحالية

- إنشاء الحساب وتسجيل الدخول.
- مكتبة أفكار وقوالب إعلانية.
- إنشاء وصف إعلاني قابل للنسخ والتنزيل.
- حفظ طلبات التصميم.
- إرسال طلبات الدفع للمراجعة اليدوية.
- لوحة إدارة لمراجعة المستخدمين والطلبات وتغيير حالة الدفع.
- ترقية الحساب إلى Pro بعد اعتماد الدفع يدويًا.

## حدود مهمة قبل الإطلاق التجاري

- إنشاء الصور والفيديوهات آليًا غير مفعّل بعد؛ يحتاج إلى ربط مزوّد ذكاء اصطناعي ومفتاح خدمة.
- الدفع الإلكتروني الفعلي غير مربوط؛ الموجود حاليًا تسجيل طلب تحويل ومراجعته يدويًا.
- قاعدة البيانات الحالية SQLite محلية. في الاستضافات السحابية قد لا تكون الملفات المحلية تخزينًا دائمًا مضمونًا بعد إعادة التشغيل أو إعادة النشر. قبل استقبال مستخدمين أو مدفوعات حقيقية، يجب نقل البيانات إلى قاعدة بيانات مُدارة ودائمة مثل PostgreSQL أو Supabase مع إعداد أسرارها.
- لا ترفع بيانات شخصية أو معلومات دفع حساسة إلى هذا الإصدار قبل استكمال التخزين الدائم ومراجعة الأمان والنسخ الاحتياطي.
